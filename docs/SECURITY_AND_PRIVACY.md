# Security, Privacy & Clinical Governance Notes

This repository is a demonstration system. Before real healthcare use:

- Do not send protected health information to unapproved external LLM services.
- Add authentication and role-based authorization.
- Encrypt data in transit and at rest.
- Add structured audit logging.
- Define retention/deletion policies.
- Add input validation, rate limiting and abuse prevention.
- Perform dependency and container vulnerability scanning.
- Add model monitoring and drift detection.
- Validate performance on representative clinical populations.
- Evaluate bias and subgroup performance.
- Establish human-in-the-loop review.
- Perform applicable regulatory and clinical safety assessment.
