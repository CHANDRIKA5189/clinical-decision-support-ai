# Project Overview

## Resume-ready description

**AI-Powered Clinical Decision Support System | Healthcare AI — NLP + ML**

- Developed a full-stack intelligent clinical decision-support prototype that analyzes user-reported symptoms and produces ranked, educational disease predictions.
- Implemented a spaCy-based NLP pipeline with normalization and symptom entity extraction from natural-language input.
- Built a Random Forest disease-classification pipeline using TF-IDF features, with optional XGBoost integration path.
- Added top-3 predictions with confidence scores and a dedicated low/medium/high severity assessment layer.
- Integrated an LLM service through an OpenAI-compatible API abstraction for user-friendly, safety-focused educational guidance.
- Added downloadable PDF report generation using ReportLab.
- Integrated browser-based voice symptom input using the Web Speech API.
- Added REST APIs, Docker deployment, tests, configuration management, and responsive React UI.
